## Propósito

Esta é a primeira versão acadêmica de referência do Pádua FloodSim, destinada a apresentações, demonstrações e registro de evolução do projeto.

O objetivo desta release não é declarar o sistema como modelo operacional de previsão ou alerta, mas congelar um estado reproduzível da plataforma experimental e de sua documentação.

## Estado funcional

A versão apresenta um mapa web interativo de Santo Antônio de Pádua com cenários oficiais de extensão de inundação publicados pelo Serviço Geológico do Brasil (SGB), organizados por cotas entre 3,00 m e 5,50 m.

Nesta etapa:

- as manchas exibidas são referências oficiais do SGB;
- bairros exibidos na interface não constituem classificação oficial de risco;
- dados INEA ainda não são convertidos automaticamente para cenários SGB;
- não há cálculo de profundidade real, velocidade ou dano;
- o modelo experimental próprio permanece separado da visualização oficial da V1.

## Contribuição do Pádua FloodSim

Esta versão consolida a contribuição computacional do projeto:

- integração de fontes geoespaciais;
- visualização web interativa;
- rastreabilidade de dados e transformações;
- arquitetura desacoplada entre dados, processamento e interface;
- documentação metodológica;
- política explícita de proveniência;
- base para futuros experimentos de cota + conectividade;
- estrutura para futura validação histórica e integração observacional.
